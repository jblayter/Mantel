Mantel theme preview

Load a theme file from this folder, or paste one, to see it on a sample of its layout (Hive, NOC or Neon) and run the build's checks (see README.md). The build is the final judge; this page is for trying colors without Android tools. Served over HTTP (for example python3 -m http.server in this folder), it also opens the themes beside it.
