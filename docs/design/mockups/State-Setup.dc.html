Mantel needs the address of your CI box. From a computer on the same network, push a config file to this TV:
Run this on your computer
adb push mantel-config.json /sdcard/Android/data/com.blayter.mantel/files/
Looking for the file every few seconds. Mantel starts on its own when it arrives.
